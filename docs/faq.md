# Справка: частые вопросы

## 1. Есть мобильная версия?

Да, это PWA — не отдельная сборка, а веб-версия, адаптированная под телефон:

- **нижняя панель вкладок** (Лента / Книги / Закладки / Добавить) вместо сайдбаров на узких экранах (≤760px);
- свайпы между главами, крупные тап-цели ≥44px, скрытие шапки при прокрутке;
- тёмная тема, тонкая полоса прогресса чтения сверху;
- **офлайн-статика**: manifest + service worker — после первой загрузки лента и открытые главы открываются без сети.

Установить на телефон: открыть сайт в браузере → меню → «Установить приложение»
(Chrome/Android) или «На экран Домой» (Safari/iOS). Подробности — README,
раздел «Возможности».

## 2. Можно собрать standalone-установку на линукс-сервер?

Да, два шага (нужен только git и Docker либо Python 3.11+):

**Вариант А — Docker (рекомендуется):**

```bash
git clone https://github.com/igorgratt/pikabureader.git
cd pikabureader
docker compose up -d
```

Данные (`data/`: БД, книги, обложки) лежат на хосте как volume — образ
пересобирать не нужно, обновление: `git pull && docker compose up -d --build`.
Проверка: `docker compose ps` (есть HEALTHCHECK по `/healthz`).

**Вариант Б — без Docker:**

```bash
git clone https://github.com/igorgratt/pikabureader.git
cd pikabureader
pip install -r requirements.txt
HOST=0.0.0.0 python app.py
```

Автозапуск — через systemd-юнит (`ExecStart=/usr/bin/python3 app.py`,
`WorkingDirectory=/opt/pikabureader`, `Environment=HOST=0.0.0.0`).
На публичном сервере поставьте пароль в `/admin` и закройте порт firewall'ом
лишним адресам.

## 3. Как показать друзьям — дать пользоваться?

Это общий сервер с профилями читателей (модель «один инстанс — свои прогресс
и заметки у каждого»):

1. Запусти сервер с `HOST=0.0.0.0` (или Docker — уже слушает `0.0.0.0`).
2. Дай друзьям адрес `http://<IP-сервера>:8000` (в той же сети — IP машины;
   из интернета — адрес VPS + открытый порт, см. п. 2).
3. Поставь **пароль** в панели владельца `/admin` — доступ по одному паролю.
4. Каждый выбирает свой профиль (аватар в шапке → `/profiles`): у каждого
   свой прогресс чтения, заметки и оценки. Новый читатель добавляется там же.
5. Библиотеку можно передать файлом: `/settings` → экспорт zip, у друга —
   импорт того же zip (книги, обложки, главы; заметки и прогресс — нет).

Что не входит (по беклогу, P2): синхронизация между устройствами (M6 — device tokens + sync API в v0.16.0).

## 4. Почему ссылки на примечания в тексте книги не работали («not found»)?

**Причина.** В EPUB ссылки внутри книги — относительные пути к файлам архива
(`../Text/notes.xhtml#vv-1`). При импорте файлы становились отдельными главами,
а href оставался как есть — браузер резолвил его в `/Text/notes.xhtml`, и сервер
отдавал 404. Дополнительно санитизация теряла `id`-якоря, даже если бы ссылка
дошла.

**Исправлено в v0.6.0:**

- при импорте такие ссылки переписываются в `/goto/<книга>/<файл>?frag=<якорь>`,
  а роут ведёт на главу с этим якорем (цель не импортирована — на первую главу
  книги, без 404);
- `id`-якоря теперь сохраняются при чистке HTML;
- у главы хранится файл-источник (миграция БД v6) — переходы переживают
  нарезку глав (F9) и zip-перенос библиотеки.

**Что делать со старыми книгами** (импортированными до v0.6.0): мёртвые ссылки
в них разово сняты — они стали обычным текстом (прыгать было некуда: якоря в
старых импортах не сохранялись). Чтобы получить рабочие ссылки на примечания,
удали книгу и импортируй заново — при повторном импорте источники и якоря
сохраняются, ссылки будут кликабельны.
