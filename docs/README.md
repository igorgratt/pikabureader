# Документация PikaBuReader

Локальная читалка для электронных книг (EPUB, FB2, PDF, TXT/Markdown) с интерфейсом в стиле [Pikabu](https://pikabu.ru): книга — «сообщество», глава — «пост» в ленте, заметки — «комментарии», оценки глав — «плюсы/минусы».

## Быстрый старт

```bash
pip install -r requirements.txt
python app.py
```

Открыть http://127.0.0.1:8000 → «+ Добавить книгу» → перетащить EPUB/FB2 → читать.

Данные хранятся локально в `data/` (SQLite-база `app.db`, обложки, картинки, загруженные файлы). Сеть и внешние сервисы не используются.
