# MVP: объём и возможности

## Идея

Электронная книга подаётся в формате ленты Pikabu, чтобы чтение ощущалось как знакомый «скроллинг постов»:

- **Книга = автор/сообщество**: обложка — аватар, «Название — Автор», страница книги похожа на страницу сообщества (оглавление, прогресс).
- **Глава = пост**: заголовок «Глава N», тело — текст главы с картинками, футер с рейтингом, заметками, закладкой и «поделиться», теги снизу.
- **Лента = список глав** всех книг: вкладки *Горячее* (по рейтингу), *Новое* (по порядку добавления), *Библиотека* (сетка обложек), *Сейчас читаю*.
- **Заметка = комментарий**: личные, с ветвлением (ответы) и оценкой.
- **Оценка главы = плюс/минус** поста: ▲/▼ в футере карточки и на странице главы.

## Что входит в MVP

### Импорт
- Загрузка файлов EPUB и FB2 (в т.ч. `.fb2.zip`) через `/add`: клик или drag&drop, до 200 МБ.
- Разбор структуры: главы по TOC/spine (EPUB) или по секциям `<section>` (FB2).
- Извлечение обложек и иллюстраций; картинки хранятся локально и отдаются сервером.
- Санитайзер HTML: остаются только текстовые теги (`p`, `h1–h6`, `strong/em`, списки, цитаты, картинки и т.п.), стили и скрипты вырезаются.
- Большие вложенные секции FB2 режутся на главы-посты, мелкие обёртки приклеиваются к соседним главам (см. [architecture.md](architecture.md#парсеры)).

### Чтение
- Лента глав с пагинацией, превью текста («Читать далее»), тегами книг.
- Страница книги: обложка, автор, аннотация, оглавление с прогрессом каждой главы, удаление книги.
- Страница главы: текст с картинками, навигация `← предыдущая глава | вся книга | следующая →`.
- Настройки чтения: тема (светлая/тёмная), шрифт (с засечками/без), размер (16–22 px), ширина колонки (узкая/средняя/широкая). Сохраняются глобально.
- Автосохранение позиции чтения: прогресс `%` обновляется при прокрутке, глава автоматически помечается прочитанной при 95%.
- Ручная отметка «Отметить прочитанным», закладки (раздел «Закладки»).

### Оценки и заметки
- Оценка главы ▲/▼ (сохраняется, влияет на сортировку «Горячего»).
- Заметки к главе: создание, ветвление через «Ответить», удаление, оценка заметки ▲/▼.

### Интерфейс
- Шапка Pikabu-стиля: лого, вкладки, поиск по книгам/авторам, кнопка импорта.
- Два сайдбара: слева — навигация и темы, справа — мои книги, «Продолжить чтение», «Горячее».
- Светлая и тёмная темы, адаптивная вёрстка (на узких экранах сайдбары скрываются).

## Чего в MVP нет (ограничения)

- **PDF** — только EPUB/FB2 (PDF запланирован первым этапом развития).
- **Поиск по тексту** — поиск работает только по названию книги и автору.
- **Заметки к выделенному тексту/абзацу** — привязаны ко всей главе.
- **Синхронизация** — один локальный профиль без авторизации, данные только на этом устройстве.
- **Импорт папки/массовый** — по одному файлу за раз.

## Сценарии использования

1. **Добавить книгу**: «+ Добавить книгу» → перетащить файл → откроется страница книги с оглавлением.
2. **Читать как ленту**: главная → *Новое* → карточка поста → «Читать далее» → страница главы, вниз — заметки.
3. **Продолжить чтение**: сайдбар «Продолжить чтение» или вкладка *Сейчас читаю* — вернётся к главе с прогрессом.
4. **Вернуться к главе позже**: «🔖 Сохранить» в футере карточки → раздел «Закладки».
5. **Сделать заметку**: на странице главы внизу в поле заметки → при необходимости «Ответить» под чужой заметкой (ветка).

## План развития

Детализированный беклог — с оценками в часах, приоритетами P0/P1/P2 и составом итераций — в [backlog.md](backlog.md). Краткая сводка этапов:

| Этап | Что | Зачем |
|---|---|---|
| 1 | Импорт PDF (разрезка по ~4000 знаков или по оглавлению) | Третий формат из исходного ТЗ |
| 2 | Заметки, привязанные к абзацу/выделению | Более точные пометки при чтении |
| 3 | Полнотекстовый поиск по главам | Быстрый возврат к прочитанному |
| 4 | Экспорт/импорт данных, синхронизация | Доступ к библиотеке с разных устройств |
| 5 | Режим «прометеев»-настроек: свои CSS-темы | Глубокая кастомизация чтения |
