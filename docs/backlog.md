# Беклог развития PikaBuReader

Детализация [плана развития из mvp.md](mvp.md#план-развития). Оценки — ориентировочные часы на задачу целиком (бэкенд + фронтенд + проверка).

**Приоритеты:**
- **P0 (now)** — ближайшая итерация, берём в работу первой
- **P1 (next)** — следующая итерация
- **P2 (later)** — когда P0/P1 закрыты или появится острая нужда

---

## E1. Форматы и импорт

| ID | Задача | Часы | Приоритет |
|----|--------|-----:|-----------|
| F1 | **PDF-импорт** через PyMuPDF: разбор текста, разбивка на главы по заголовкам/шрифтам, fallback — нарезка по ~4000 знаков | 8 | **P0** |
| F2 | Обложка PDF: рендер первой страницы в JPEG | 2 | P1 |
| F3 | Массовый выбор файлов в `/add` (несколько книг за раз) | 2 | P1 |
| F4 | Дедупликация при импорте: если книга с таким же title+author уже есть — предложить пропустить/обновить | 3 | **P0** |
| F5 | Понятные ошибки импорта в UI (карточка вместо flash: формат, DRM, повреждённый файл) | 2 | P1 |
| F6 | Импорт `.txt`/`.md` (главы по `# Заголовок`) | 2 | P2 |
| F7 | Фоновая обработка больших книг: импорт в фоне + страница статуса (сейчас запрос блокируется) | 4 | P2 |

| F9 | **Режимы разбивки при импорте**: выбор гранулярности постов — компактные (~2000 знаков), текущая (по главам книги), крупные (свернуть подсекции в одну главу); с предпросмотром до импорта | 4 | P1 |

## Порядок работ (по волнам, usability-ранжирование)

Утверждённый порядок: сначала непрерывность чтения, потом телефон, затем PDF+поиск; модель шаринга — **общий сервер с профилями**.

**Волна 0 — Фундамент (~8 ч):** Q1 миграции БД → Q2 тесты парсеров. ✅
**Волна 1 — Непрерывность чтения (~9 ч):** M8 → M9 → R3 → R4. ✅
**Волна 2 — Телефон (~12 ч):** M1 → M2 → M3 → M10 (+ M7). ✅
**Волна 3 — Библиотека растёт (~22–26 ч):** F1 → F2 → F4 → N1 → N2 (+ F9 опционально в конце). ✅
**Волна 4 — Глубина чтения (~16–19 ч):** R1 → R2 → N3 → M4 (+ R5). ✅
**Волна 5 — Общий сервер (~27 ч):** D3 → D2 → D1 → D4 → D10 → D6 → Q3 (D7 — хвостом по запросу; D5, D8 — по запросу друзей). ✅ (D6 — сборка проверена в CI)
**Волна 6 — P1-хвосты (~19 ч):** F3 → F5 → F9 → N4 → N5 → N6 → M5 → Q5. ✅ (контраст закрыт тестом на пары цветов из CSS)
**Волна 7 — Инструменты чтения (P2, ~10 ч):** Q4 (E2E smoke: Playwright — импорт → лента → глава → заметка) → R6 («читать далее» в ленте) → N7 («недавно читал»). 🔜

**Горизонт (остальной P2, ~56 ч):** F6/F7/F8 (импорт txt/фон/миниатюры), R7/R8/R9 (статистика/шрифты/автопрокрутка), N8 (все заметки), M6 (синхронизация), M11 (Android), D5/D7/D8 (деплой/ссылка на книгу/Windows-zip).

Итого волн 0–6: **~124 ч**.
