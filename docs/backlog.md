# Беклог развития PikaBuReader

Детализация [плана развития из mvp.md](mvp.md#план-развития). Оценки — ориентировочные часы на задачу целиком (бэкенд + фронтенд + проверка).

**Приоритеты:**
- **P0 (now)** — ближайшая итерация, берём в работу первой
- **P1 (next)** — следующая итерация
- **P2 (later)** — когда P0/P1 закрыты или появится острая нужда

## Порядок работ (по волнам, usability-ранжирование)

Утверждённый порядок: сначала непрерывность чтения, потом телефон, затем PDF+поиск; модель шаринга — **общий сервер с профилями**.

**Волна 0 — Фундамент (~8 ч):** Q1 миграции БД → Q2 тесты парсеров. ✅
**Волна 1 — Непрерывность чтения (~9 ч):** M8 → M9 → R3 → R4. ✅
**Волна 2 — Телефон (~12 ч):** M1 → M2 → M3 → M10 (+ M7). ✅
**Волна 3 — Библиотека растёт (~22–26 ч):** F1 → F2 → F4 → N1 → N2 (+ F9 опционально в конце). ✅
**Волна 4 — Глубина чтения (~16–19 ч):** R1 → R2 → N3 → M4 (+ R5). ✅
**Волна 5 — Общий сервер (~27 ч):** D3 → D2 → D1 → D4 → D10 → D6 → Q3 (D7 — хвостом по запросу; D5, D8 — по запросу друзей). ✅ (D6 — сборка проверена в CI)
**Волна 6 — P1-хвосты (~19 ч):** F3 → F5 → F9 → N4 → N5 → N6 → M5 → Q5. ✅ (контраст закрыт тестом на пары цветов из CSS)
**Волна 7 — Инструменты чтения (P2, ~10 ч):** Q4 (E2E smoke: Playwright — импорт → лента → глава → заметка) → R6 («читать далее» в ленте) → N7 («недавно читал»). ✅ (v0.6.1, v0.7.0, v0.7.1)
**Волна 8 — Агенто-готовность (P2, ~6 ч):** Q7 (AGENTS.md: команды, процесс релиза, подводные камни) → D11 (CLI `pika.py`: serve/import/list/stats/backup, `--json`). ✅ (v0.8.0)
**Волна 9 — QA-цикл (P2, ~5 ч):** Q8 (регресс-обход роутов, security-review + фиксы, docs/security.md). ✅ (v0.9.0)

**Волна 10 — Текст и заметки (P2, ~10 ч):** F6 (импорт txt/md) → R7 (статистика чтения) → N8 (все заметки). ✅ (v0.10.0, v0.11.0, v0.12.0)
**Волна 11 — Удобства чтения (P2, ~6 ч):** R8 (свои шрифты) → R9 (автопрокрутка). ✅ (v0.13.0)
**Волна 12 — Импорт (P2, ~7 ч):** F7 (фоновая обработка) → F8 (миниатюры иллюстраций). ✅ (v0.14.0)
**Волна 13 — Дистрибуция (P2, ~13 ч):** D5 (гайд по публичному деплою) → D7 (публикация книги по ссылке) → D8 (Windows-zip). ✅ (v0.15.0)
**Волна 14 — Синхронизация (P2, ~12 ч):** M6 (WebDAV / мини-сервер с токеном). ✅ (v0.16.0)
**Волна 15 — Android (P2, ~6 ч):** M11 (PWA доустановка + TWA/APK). → v0.17.0
**Финал — v1.0.0:** ревизия README/CHANGELOG, полный QA-прогон, GitHub Release с бинарями/инструкциями.

Итого волн 0–15: **~199 ч** + финализация v1.0.0. Все задачи бэклога запланированы.
