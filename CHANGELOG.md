Каждая версия сопровождается тегом `vX.Y.Z` в git и должна проходить тесты:

```bash
python -m pytest tests/ -q
```

## v0.6.0 — Ссылки в книге: сноски без 404 (2026-09-25)

**Ссылки внутри книги (EPUB)**
- Ссылки между файлами книги (`../Text/notes.xhtml#vv-1` — сноски, примечания,
  переходы по главам) больше не отдают «not found»: при импорте они переписываются
  в `/goto/<book>/<файл>?frag=<якорь>`, роут ведёт на главу с этим якорем
  (файл не импортирован — на первую главу книги, без 404)
- Санитизация сохраняет `id`-якоря (`<span id>`, `<a id>` и др. раньше терялись
  при чистке тегов) — без них прыжок к конкретной сноске невозможен
- У главы хранится файл-источник: миграция БД **v6** (`chapters.source`);
  F9-режимы разбивки и zip-экспорт/импорт библиотеки ведут `source` параллельно
  главам, при импорте zip ссылки `/goto/<старый id>/` переписываются под новую книгу
- Старые импорты (до v0.6.0): разовая правка в миграции — мёртвые относительные
  ссылки сняты, текст остался (якорей в старых книгах почти нет — прыжать было некуда)
- `restorePosition` не мешает переходу по якорю (`location.hash`)
- Роут `GET /goto/<book_id>/<path>`, тесты: перезапись ссылок, выравнивание
  `sources` в F9-режимах, `/goto`-редиректы, миграция v6, `neutralize_dead_links`

## v0.5.1 — UI-багфиксы после ручной проверки (2026-09-25)

**Исправлено**
- Панель оглавления на странице чтения больше не «прилипает»: авторский
  `.toc-pop { display: flex }` перебивал UA-стиль `[hidden]`, из-за чего
  оглавление было всегда видно и перекрывало область чтения, правую часть
  полосы прогресса и нижние кнопки. Глобальное правило
  `[hidden] { display: none !important }` (в стиле HTML5 Boilerplate)
  закрывает класс багов для всех элементов с атрибутом `hidden`
  (`.toc-pop`, `.quote-chip`, `.note-text`, `.sel-pop`)
- Service worker: `CACHE` поднят до `pikabu-v2` (статика cache-first — без
  бампа браузеры не увидят новый CSS); старые кэши удаляются при активации
- Тест `test_hidden_attribute_overrides_display` (70 тестов)

## v0.5.0 — Волна 6: P1-хвосты (2026-09-25)

**Импорт**
- Мультизагрузка (F3): выбор нескольких файлов одной кнопкой — каждый в свою
  карточку результата; не больше 50 за раз
- Читаемые ошибки (F5): карточки с причиной и подсказкой («Формат не
  поддерживается», «Файл повреждён», «Файл не читается», «Ошибка разбора»)
  вместо мелких flash-сообщений
- Предпросмотр импорта (F9): `/add?preview=1` → `/add/preview` — список глав,
  режимы нарезки: `parts` (по разделам), `compact` (длинные главы рвутся по
  ~2000 знаков с пометкой «(i/n)»), `merge` (мелкие секции склеиваются `<hr>`)

**Лента и библиотека**
- Фильтр по тегу (N4): `/?tag=...` — теги на карточках кликабельны, активный
  тег показан полосой и сохраняется в пагинации
- Сортировка библиотеки (N5): новые / по названию / по автору / по прогрессу
  (`SUM(done)`, отмеченные прочитанными вперёд)

**Закладки и заметки**
- Закладка запоминает место (N6): при включении закладки сохраняется ближайший
  к верху абзац (до 300 знаков), виден на странице закладок; выключение —
  очищает цитату; миграция БД v5 (`state.bookmark_quote`)
- Экспорт заметок в Markdown (M5): `GET /notes/export` (+ `?book_id=`) —
  дерево «книга → глава → заметки» с цитатами; ссылки в главе книги и в
  настройках

**Контраст и стиль (Q5)**
- WCAG AA 4.5:1 для основных пар цветов в обеих темах: вторичный текст,
  ссылки, зелёный/красный статусы; исключение — тёмный текст на жёлтом
  акценте; тест `test_theme_contrast_wcag_aa` проверяет токены прямо из CSS
- Исправлена сортировка библиотеки: параметр `sort` теперь реально доходит
  до SQL (в v0.4.x подсветка вкладки работала, порядок — нет)

- Тесты: 69 (мультимпорт, ошибки, предпросмотр, теги, сортировка, цитата
  закладки, экспорт md, контраст тем)

## v0.4.1 — Docker дошёл до ума (2026-09-25)

- `GET /healthz`: лёгкий healthcheck (без БД и без входа) — используется в
  `HEALTHCHECK` Dockerfile и в `healthcheck:` docker-compose
- CI: job `docker` — сборка образа, запуск контейнера, smoke-тест
  (healthz, лента, страница входа, статус health, версия внутри образа);
  D6 закрыт: сборка проверена на каждом push
- Безопасность сессий: вместо фиксированного `secret_key` — `SECRET_KEY`
  из env или случайный, сохранённый в `data/secret_key` (переживает
  рестарты через volume)
- Dockerfile: пин `python:3.13-slim-bookworm`; `.dockerignore` расширен
  (`.github`, `docs`, `.pytest_cache`, md-файлы)
- Тесты: 54 (healthz)

## v0.4.0 — Волна 5: общий сервер (2026-09-25)

**Доступ**
- Пароль инстанса (D3): общий пароль на весь сервер, хранится как
  pbkdf2-hmac-sha256 (120k итераций) с солью; страницы и API закрыты
  до входа, сессия в cookie; пустой пароль — открытый инстанс
- Панель владельца (D10): `/admin` — смена пароля, профили, бэкап/восстановление,
  размер данных, лог импорта (последние 50 строк), переиндексация FTS

**Читатели**
- Профили (D2): несколько читателей на одном сервере — свой прогресс,
  заметки, оценки и закладки; переключение на `/profiles` («Кто читает?»),
  аватар в шапке; миграция БД v4 (`profiles`, `state`/`notes.profile_id`, `ratings`)

**Оценки**
- Голос каждого профиля отдельно: свой ±1 в таблице `ratings`,
  агрегат в `chapters.rating`; повторный клик не задваивает голос

**Передача библиотеки**
- Экспорт (D4): чекбоксы в «Библиотеке» → `GET /api/library.zip?ids=…` —
  `manifest.json` + обложки + картинки глав, без прогресса и заметок
- Импорт от друга: секция на «Добавить книгу» → `POST /api/library/import`
  с дедупликацией, FTS-индексацией и ремапом путей картинок под новый book_id
- Лог импорта (Q6): `data/import.log` — действие, объём, время

**Качество**
- CI (Q3): GitHub Actions — pyflakes + pytest на push/PR
- Документация: README (версия 0.4.0, пароль, профили, передача, панель),
  D1 закрыт; D6 — Docker-файлы консистентны, сборка не проверялась
- Тесты: 53 (логин/401, изоляция профилей, оценки, экспорт/импорт, миграция v4)

## v0.2.0 — Волны 0–3: PDF, поиск, телефон (2026-09-25)

**Форматы и импорт**
- PDF-импорт через PyMuPDF (F1): главы по заголовкам — эвристика по размеру
  и жирности шрифта; без заголовков — нарезка по ~4000 знаков
- Обложка PDF: рендер первой страницы в JPEG (F2)
- Дедупликация при импорте: повтор title+author → ссылка на существующую
  книгу вместо дубля (F4)

**Поиск**
- Полнотекстовый поиск по главам: SQLite FTS5, индекс при импорте,
  выдача с превью контекста и подсветкой (N1)
- Переход к результату: `?find=` подсвечивает первое совпадение в главе (N2)

**Непрерывность чтения**
- Прогресс чтения главы (data-read-pct + восстановление позиции) (M8)
- Кнопка «Продолжить чтение» на странице книги (M9)
- Тонкий прогресс-бар чтения в шапке (R3)
- Фиксированная кнопка «Следующая глава» (R4)

**Телефон**
- PWA: manifest, service worker, иконки (M1)
- Свайпы между главами (M2)
- Нижняя панель вкладок (M3)
- Тап-цели ≥44px, скрытие шапки при скролле, кнопка fullscreen (M10)
- Тема по `prefers-color-scheme` без вспышки (M7)

**Данные и качество**
- Миграции БД: `PRAGMA user_version`, ошибка при версии схемы новее кода (Q1)
- Тесты: 34 (парсеры, миграции, PDF) (Q2)
- Хост/порт/дебуг через env (`HOST`, `PORT`, `FLASK_DEBUG`)
