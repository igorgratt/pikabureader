# PikaBuReader

Локальная читалка для электронных книг в формате ленты Pikabu: книга — «сообщество», глава — «пост», заметки — «комментарии», оценки глав — «плюсы/минусы».

## Возможности MVP

- Импорт **EPUB** и **FB2** (и `fb2.zip`) через `/add` (кнопка «+ Добавить книгу»), drag&drop в браузере
- Лента глав: вкладки **Горячее** (по рейтингу), **Новое** (по порядку), **Библиотека**, **Сейчас читаю**
- Страница книги (обложка, автор, оглавление, прогресс прочитанного)
- Страница главы: чтение, навигация `← глава →`, **настройки** (шрифт, размер, ширина, светлая/тёмная тема)
- Оценки глав (▲/▼), закладки, автоматический прогресс чтения (запоминает позицию)
- Личные заметки к главам с ветвлением (ответы), оценкой и удалением
- Понятная на Pikabu вёрстка: карточки постов, шапка, сайдбары, тёмная тема
- Удаление книги со всеми данными

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

Открыть http://127.0.0.1:8000

### В Docker

```bash
docker compose up -d
```

Открыть http://127.0.0.1:8000 — данные книги (`data/`) хранятся на хосте как volume, образ пересобирать не нужно.

### С телефона или для друзей

Сервер по умолчанию слушает только localhost. Чтобы открыть с телефона в той же Wi-Fi-сети:

```bash
HOST=0.0.0.0 python app.py        # Windows: set HOST=0.0.0.0 && python app.py
```

Затем открой на телефоне `http://<IP-компьютера>:8000` (IP смотреть через `ipconfig`). В Docker это работает сразу.

Полная документация — в [docs/](docs/README.md): [объём MVP](docs/mvp.md), [архитектура](docs/architecture.md), [беклог развития](docs/backlog.md).

## Структура

```
app.py            # Flask-приложение: роуты, API, импорт
db.py             # SQLite-схема и подключение (data/app.db)
parsers/__init__.py  # парсеры EPUB (ebooklib) и FB2 (xml), санитайзер HTML
templates/        # Jinja-шаблоны в стиле pikabu.ru
static/css/       # CSS-клон интерфейса Pikabu (светлая/тёмная тема)
static/js/        # рейтинги, заметки, прогресс, настройки чтения
data/             # база, обложки, картинки, загруженные файлы (создаётся сама)
```

## Формат данных

- `books` — книга (название, автор, обложка, теги, аннотация)
- `chapters` — главы (порядок, заголовок, очищенный HTML, оценка)
- `notes` — заметки-комменты (дерево через `parent_id`, оценка)
- `state` — закладка, прочитано, прогресс `%`
- `settings` — тема/шрифт/размер/ширина
