# PikaBuReader

Локальная читалка для электронных книг в формате ленты Pikabu: книга — «сообщество», глава — «пост», заметки — «комментарии», оценки глав — «плюсы/минусы».

**Версия:** `0.14.0` — см. [CHANGELOG.md](CHANGELOG.md); версии отмечены тегами `vX.Y.Z` в git.

## Возможности

- Импорт **EPUB**, **FB2** (и `fb2.zip`), **PDF**, **TXT/Markdown** через `/add` (кнопка «+ Добавить книгу»), drag&drop в браузере, **несколько файлов за раз**; дубликаты и ошибки — читаемыми карточками; **предпросмотр с выбором режима** (по разделам / компактно / склеить мелкие)
- Полнотекстовый **поиск по главам** с превью и подсветкой совпадения в тексте
- Лента глав: вкладки **Горячее** (по рейтингу), **Новое** (по порядку), **Библиотека**, **Сейчас читаю**; **фильтр по тегу** (клик по тегу) и сортировка библиотеки (новые/название/автор/прогресс)
- Страница книги (обложка, автор, оглавление, прогресс прочитанного, «Продолжить чтение»)
- Страница главы: чтение, навигация `← глава →` и свайпами, **настройки** (шрифт, размер, ширина, светлая/тёмная тема), прогресс-бар и кнопка «Следующая глава», панель **«☰ Оглавление»** с прогрессом по главам
- **Горячие клавиши**: `←`/`→` — главы, `B` — закладка, `/` — поиск
- Оценки глав (▲/▼) — **у каждого читателя свой голос**, закладки с **цитатой места**, автоматический прогресс чтения
- Личные заметки: ветвление (ответы), оценка, **заметки к выделенному тексту с цитатой**, правка с датой, **экспорт всех заметок в Markdown**
- **Общий сервер**: пароль инстанса (вход на все страницы), **профили читателей** со своим прогрессом/заметками/оценками («Кто читает?» в аватаре)
- **Передача библиотеки**: экспорт отмеченных книг в zip (обложки и картинки внутри) и импорт у друга — кнопки на страницах «Библиотека» и «+ Добавить книгу»
- **Панель владельца** `/admin`: пароль, профили, бэкап/восстановление, лог импорта, переиндексация поиска
- PWA: можно установить на телефон (manifest + service worker), нижняя панель вкладок, тап-цели ≥44px
- Понятная на Pikabu вёрстка: карточки постов, шапка, сайдбары, тёмная тема, контраст по WCAG AA
- Удаление книги со всеми данными

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

Открыть http://127.0.0.1:8000

### CLI (без браузера)

```bash
python pika.py serve --port 8000        # то же, что python app.py
python pika.py import book.epub report.fb2 --split compact
python pika.py list --json              # список книг для скриптов
python pika.py stats                    # версия, схема, счётчики, размер data/
python pika.py backup data-backup.zip   # бэкап data/ в zip
```

Коды возврата: 0 — успех, 1 — ошибка, 2 — неверные аргументы.
Подробности — `python pika.py --help`.

### Пароль и читатели

- Пароль задаётся в **панели владельца** `http://127.0.0.1:8000/admin` (пока не задан — доступ открыт). Пустое поле снимает пароль.
- Профили читателей — на странице аватара в шапке (`/profiles`): свой прогресс, заметки и оценки у каждого.

### В Docker

```bash
docker compose up -d
```

Открыть http://127.0.0.1:8000 — данные книги (`data/`) хранятся на хосте как volume, образ пересобирать не нужно. У контейнера есть `HEALTHCHECK` по `/healthz`, статус виден через `docker compose ps`. На публичном сервере задай `SECRET_KEY` в `docker-compose.yml` (иначе секрет сгенерируется автоматически в `data/secret_key`).

Сборка образа, запуск контейнера и smoke-тест гоняются в CI (GitHub Actions) на каждый push — D6 проверен.

### С телефона или для друзей

Сервер по умолчанию слушает только localhost. Чтобы открыть с телефона в той же Wi-Fi-сети:

```bash
HOST=0.0.0.0 python app.py        # Windows: set HOST=0.0.0.0 && python app.py
```

Затем открой на телефоне `http://<IP-компьютера>:8000` (IP смотреть через `ipconfig`). В Docker это работает сразу.

## Структура

```
app.py            # Flask-приложение: роуты, API, импорт
db.py             # SQLite-схема и подключение (data/app.db)
parsers/__init__.py  # парсеры EPUB (ebooklib) и FB2 (xml), санитайзер HTML
templates/        # Jinja-шаблоны в стиле pikabu.ru
static/css/       # CSS-клон интерфейса Pikabu (светлая/тёмная тема)
static/js/        # рейтинги, заметки, прогресс, настройки чтения
data/             # база, обложки, картинки, загруженные файлы (создаётся сама)
```

## Формат данных

- `books` — книга (название, автор, обложка, теги, аннотация)
- `chapters` — главы (порядок, заголовок, очищенный HTML, агрегат оценок)
- `profiles` — читатели (для общего сервера)
- `notes` — заметки-комменты (дерево через `parent_id`, цитата, свой профиль)
- `state` — закладка, прочитано, прогресс `%` (своя строка на профиль)
- `ratings` — голос ±1: главы/заметки × профиль
- `settings` — тема/шрифт/размер/ширина, хеш пароля инстанса
